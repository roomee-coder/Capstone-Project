# TaskFlow

A full-stack, AI-assisted task management platform built with FastAPI, SQLAlchemy, and vanilla JavaScript.

- **Backend** (`backend/`) — REST API for projects, tasks, and users, with hand-rolled sorting/search algorithms and an AI-assisted quick-add feature that parses free-text task descriptions into structured records.
- **Frontend** (`frontend/`) — A responsive dashboard that renders tasks live from the backend, with add/edit/delete/mark-done wired end-to-end.
- **Detailed setup, endpoint docs, and algorithm write-ups** are in [`backend/README.md`](backend/README.md).

See `backend/README.md` for how to run the project locally.
